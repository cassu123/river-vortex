# openWakeWord — local wake word detection, no licence key and no account.
# Chosen over Porcupine because Picovoice needs an access key, which is a
# commercial dependency sitting in the one part of the system meant to prove
# nothing leaves the house. River Song uses openWakeWord too, so this also
# makes both halves agree on what the wake word is.
#
# Models are baked into the unit image and loaded from disk — never downloaded
# at runtime. See audio/models/README.md.
openwakeword==0.6.0
